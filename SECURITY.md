# Security Policy

## Supported versions

Only the latest minor release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub Security Advisories](https://github.com/kerimakmyradov/eslint-plugin-nest-drift/security/advisories/new).

You can expect an acknowledgement within 7 days. Once a fix is released, the advisory is published with credit to the reporter (unless you prefer to stay anonymous).

This plugin only reads source code during linting and makes no network requests, so the most likely issues are in its dependencies or in supply-chain aspects of the release process.
